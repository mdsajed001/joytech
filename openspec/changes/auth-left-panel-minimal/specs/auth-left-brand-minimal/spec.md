## Purpose

Specifies the minimalist, bold brand presentation for the desktop authentication visual panel, avoiding marketing text clutter.

## ADDED Requirements

### Requirement: Minimal Centered Brand Anchor
The desktop authentication visual panel MUST display the **JOYTECH** brand name centered within the view in prominent typography without descriptive marketing paragraphs or bullet checklists.

#### Scenario: User views the desktop auth page
- **WHEN** user loads `/auth` or `/auth/verify` on a desktop viewport
- **THEN** the left panel centers the bold JOYTECH brand text
- **AND** no marketing body paragraphs, trust checklists, or category badges are displayed
- **AND** the ambient drifting bubbles and floating gadget icons remain visible around the brand
