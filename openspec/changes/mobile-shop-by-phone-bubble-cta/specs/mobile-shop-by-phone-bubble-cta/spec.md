## Purpose

Provides a vibrant, animated primary blue container with floating bubbles and a wiggling 3D phone icon inside the mobile navigation drawer.

## ADDED Requirements

### Requirement: Breathing Blue Container with Floating Bubbles
The system SHALL render the "Shop by Phone" section in the mobile navigation drawer with a primary brand blue background that subtly pulses with a breathing rhythm and contains floating translucent bubbles.

#### Scenario: Viewing mobile menu drawer
- **WHEN** the user opens the mobile navigation menu drawer
- **THEN** the "Shop by Phone" section displays a vibrant primary blue card with smooth breathing animation and drifting bubbles behind the CTA.

---

### Requirement: Embedded White CTA with 3D Wiggling Phone
The system SHALL embed a solid white CTA card within the blue section displaying "Shop by Phone", localized subtitle, and a 3D smartphone graphic that wiggles every 5 seconds.

#### Scenario: Observing 3D phone icon animation
- **WHEN** the user watches the "Shop by Phone" card in the open mobile drawer
- **THEN** the 3D phone icon executes an eye-catching wiggle vibration burst every 5 seconds and returns to rest between intervals.

#### Scenario: Tapping the CTA card
- **WHEN** the user taps the white "Shop by Phone" card on mobile
- **THEN** the card provides tactile tap feedback without triggering page navigation or modal side-effects.
