## Purpose

Defines top-alignment standards for the Flash Sale section header to ensure visual symmetry between the title and countdown label.

## ADDED Requirements

### Requirement: Top-Row Header Alignment
The Flash Sale section header container SHALL use top alignment (`items-start`) to visually pair the top-row title and label elements across the header bar.

#### Scenario: Visual alignment of top elements
- **WHEN** the Flash Sale section header renders
- **THEN** the top edge of the "⚡ Flash Sale" title aligns with the top edge of the "Ends in:" label
- **AND** the "Up to 40% OFF" badge renders parallel to the countdown digit boxes
