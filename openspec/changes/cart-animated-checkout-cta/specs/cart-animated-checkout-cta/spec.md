## Purpose

Applies the smooth ambient dual-bubble translation animation to cart checkout CTA buttons for consistent micro-interaction delight.

## ADDED Requirements

### Requirement: Ambient Dual-Bubble Animated Checkout Buttons
Primary checkout buttons in the cart experience SHALL display a continuous, smooth dual-bubble position interchange animation identical in timing (10s cycle) and ease to the search button.

#### Scenario: User observes the mobile checkout CTA
- **WHEN** user views the cart page on mobile
- **THEN** the checkout CTA displays moving ambient radial gradient bubbles in the background without obstructing inner text and icon readability

#### Scenario: User observes the desktop order summary CTA
- **WHEN** user views the desktop order summary
- **THEN** the Proceed to Checkout button displays smooth ambient moving bubbles with hover and active state transitions
