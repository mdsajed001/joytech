## Purpose

Defines requirements for the header search bar placeholder text and layout.

## ADDED Requirements

### Requirement: Search bar uses simple placeholder text
The header search inputs SHALL display `"Search"` as the placeholder text without additional descriptive phrases.

#### Scenario: Search input rendering
- **WHEN** the search input field is empty and un-focused
- **THEN** it displays the placeholder text `"Search"` on both mobile and desktop viewports
